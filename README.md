# tech-demos

A sticky monorepo of small, single-user tech playgrounds. Each demo lives in `apps/<slug>/` and is self-contained (`bun install && bun run dev`).

New demos are planned with `skills/project-planning/` and land as pull requests with a screenshot and a video of the running app.

See [AGENTS.md](./AGENTS.md) for layout and cloud-agent rules.
