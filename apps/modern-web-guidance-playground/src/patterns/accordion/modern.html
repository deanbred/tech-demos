The same accordion from native <details>: a shared name gives exclusivity, CSS animates the height. No JS.

What is this?

Native disclosure elements. Semantics, keyboard support and state come free.

How does the animation work?

CSS transitions ::details-content's block-size to its intrinsic size via interpolate-size.

And the exclusivity?

The shared name="faq" attribute: the browser closes the others, like radio buttons.
